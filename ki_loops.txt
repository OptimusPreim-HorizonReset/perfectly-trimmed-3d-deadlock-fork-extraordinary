4️⃣ Loop‑Engine für KI‑Iteration
Du bekommst eine Mini‑Loop‑Engine, die KI‑Agenten steuert:

ai/loops/loop_engine.py
python
class LoopEngine:
    def __init__(self, agent):
        self.agent = agent

    def iterate(self, file):
        suggestion = self.agent.improve(file)
        apply_patch(file, suggestion)
        result = run_tests()
        log_iteration(file, suggestion, result)
        return result
Damit entsteht ein echter KI‑Regelkreis:

KI erzeugt Änderung

Patch wird angewendet

Tests laufen

KI korrigiert

Logs dokumentieren
